Descripción del proyecto

Este proyecto consiste en el desarrollo de una aplicación web para un negocio llamado Food Store, orientada a la visualización y gestión de productos tipo e-commerce.
La aplicación permite visualizar un catálogo dinámico de productos, realizar búsquedas por nombre, filtrar por categorías y gestionar un carrito de compras.

El carrito permite agregar productos, modificar cantidades, eliminar ítems y vaciar completamente la selección. Además, se implementa persistencia de datos utilizando localStorage, lo que permite mantener la información incluso al recargar la página.

El desarrollo se realizó utilizando HTML, CSS, JavaScript y TypeScript, aplicando manipulación del DOM y una estructura modular del código.

-------------------

Instrucciones para ejecutarlo :

1. Clonar o descargar el repositorio del proyecto.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Instalar las dependencias (si corresponde):
   pnpm install
4. Ejecutar el servidor de desarrollo:
   pnpm dev
5. Abrir el navegador en la URL indicada (generalmente http://localhost:5173).
6. Navegar entre las páginas (Home y Carrito) para utilizar las funcionalidades.
